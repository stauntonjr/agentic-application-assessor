# Issue #26: adopted validator runtime isolation

## 1. Outcome and why it matters

`VERIFIED`: Adopted harness validation no longer resolves the Actions supply-chain implementation
through an application's `tools` namespace. The implementation now lives under
`harness.runtime`; copied `tools/harness_check.py` imports that package directly, while the
historical `tools/check_actions_supply_chain.py` command remains a thin compatibility wrapper.

This lets an adopter preserve an incompatible application-owned module with the same filename and
still receive structured provisional-adoption evidence instead of an import traceback.
