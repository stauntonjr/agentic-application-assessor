# Release evidence checklist

- Exact source revision and clean worktree.
- Independent harness and product versions, canonical product-version source, and current release-impact assessments.
- Reproducible build and immutable artifact identity or checksum.
- Unit, integration, contract, public-interface, and end-to-end checks required by the profile.
- Clean-install or clean-environment smoke test.
- Dependency, license, secret, static-analysis, and supply-chain review.
- Schema and data migration plan with compatibility window.
- Deployment plan, health signals, alerts, rollback, backup, and recovery.
- User, operator, API, and changelog documentation.
- Issue and Project acceptance state.
- Independent review for high-risk changes.
- Named human release authority and outstanding conditions.
