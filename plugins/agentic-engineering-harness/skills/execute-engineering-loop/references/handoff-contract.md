# Handoff contract

Every delegated lane returns:

- role and actor identity;
- governing Issue and acceptance criteria;
- repository, branch, worktree, and start revision;
- exact owned scope and changed paths;
- semantic, interface, schema, dependency, and operational effects;
- commands, results, artifacts, and boundaries proven;
- findings, blockers, retries, dependencies, and residual risks;
- external actions taken or still requiring authorization;
- recommended loop and GitHub status.

Return raw artifact paths and concise conclusions. Do not include hidden reasoning or full transcripts.
