Use the `loop-report` skill for run `${1:-the active or most recent run}`.

Build the report from the deterministic run record, criterion-linked checks, baseline-relative scope, the revision-bound verdict, handoffs, decisions, Git, and authorized GitHub evidence. Label verified, reported, and inferred claims. State every scope violation, stale or absent verdict, unverified boundary, and human decision still required.
